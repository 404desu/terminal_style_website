# terminal_style_website

A portfolio pretending to be a terminal.

Type commands. Explore around. Find links.
Try not to `rm -rf` anything.

## Run it

It's just HTML, CSS, and JavaScript — no build system, no framework, no mysterious dependencies.

Open `index.html` in your browser, or run it through any local static server.

## Customize it

Most of the fun stuff lives in:

```text
js/commands.js
```

That's where you can change:

* Terminal text
* Commands
* Social links
* Projects
* Certifications
* Banner
* Contact information

The styling lives in the CSS, so feel free to make the terminal look like your own machine.

## Commands

The site behaves like a tiny interactive shell.

Try:

```text
help
whoami
social
projects
certifications
history
banner
clear
```

There may or may not be anything interesting hiding in there.
Probably best not to `sudo` anything.

## Tech

No framework. No build step. Just a browser and some code.
