# terminal_style_website

A terminal-inspired portfolio built with plain HTML, CSS, and JavaScript.

This repo is a playful command-driven landing page for a developer portfolio. Type commands, explore links, and read the output like you're in a retro shell.

## Run it locally

1. Open `index.html` in a browser.
2. Or use a simple static server if you want a more realistic local setup.

## Customize

- Edit `js/commands.js` for terminal text, commands, and links.
- Update the banner, social list, and project entries inside `js/commands.js`.
- Change the GitHub handle and repository URL in the banner block there.

## What it is

- A terminal-style portfolio website
- Built with HTML/CSS/JavaScript
- Designed to feel like interacting with a shell
